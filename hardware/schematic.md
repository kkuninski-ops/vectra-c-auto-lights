# Хардуерна схема — Vectra C Auto Lights

## Блок схема

```
                        ┌──────────────────────────────────────────────┐
KL30 ──[F1:1A]─────────►│ LM7805 → 5V → ESP32                         │
                        │                                              │
KL30 ──[F2:15A]────────►│ IRF4905 (P-MOSFET) → [D2] ──► Ксенон баласт│
                        │                                              │
KL30 ──[F3:5A]─────────►│ Реле K1 (Габарити)                    ESP32 │◄── BT
                        │ Реле K2 (Мъгла)                             │
                        │                                              │
Vbat ──[47k/10k]───────►│ ADC → детекция на двигател                  │
KL18 ──[PC817]─────────►│ GPIO35 — ACC вход                           │
AUTO ──[PC817]─────────►│ GPIO32 — AUTO вход                          │
UNLOCK─[PC817]─────────►│ GPIO33 — Unlock вход (interrupt)            │
                        └──────────────────────────────────────────────┘
                               │            │           │
                           Ксенон       Габарити      Мъгла
                          (+BCM via D3) (+BCM via D5) (+BCM via D7)
```

---

## Секция 1 — Захранване на контролера

```
KL30 (+12V постоянно)
  │
 [F1 — предпазител 1A]
  │
 [D1 — 1N4007] ──► (реверсна защита)
  │
 [TVS — P6KE15A] ──► GND  (защита от load dump до ~25V)
  │
 [LM7805]
  IN ──── горе
  GND ─── маса
  OUT ──► [C1: 100µF/25V] + [C2: 100nF] ──► GND
  OUT ──► ESP32 VIN (5V)
```

**Бележка:** LM7805 може да се замени с DC-DC buck (LM2596 модул) за по-малко топлина.

---

## Секция 2 — Детекция на напрежение (двигател работи)

```
KL30 (+12V)
  │
 [R1 — 47kΩ]
  │
  ├──► GPIO34 (ADC)
  │
 [R2 — 10kΩ]
  │
 GND

Vbat = Vadc × 57 / 10
Праг ON : 13.2V (алтернаторът зарежда → двигателят работи)
Праг OFF: 12.8V (хистерезис)
```

---

## Секция 3 — Входове KL18/ACC и AUTO (еднакви схеми)

```
12V сигнал (KL18 или AUTO проводник)
  │
 [R3/R5 — 4.7kΩ]
  │
 PC817 — анод
 PC817 — катод ──► GND

 PC817 — колектор ──► [R4/R6 — 10kΩ] ──► 3.3V
 PC817 — колектор ──► GPIO35 (ACC) / GPIO32 (AUTO)
 PC817 — емитер  ──► GND

Логика: 12V на входа → LED свети → транзистор ON → GPIO = LOW (активен)
```

---

## Секция 4 — Входен Unlock pulse

```
Unlock проводник (12V pulse ~200-500ms при отключване)
  │
 [R7 — 4.7kΩ]
  │
 PC817 — анод
 PC817 — катод ──► GND

 PC817 — колектор ──► [R8 — 10kΩ] ──► 3.3V
 PC817 — колектор ──► GPIO33 (FALLING interrupt)
 PC817 — емитер  ──► GND
```

---

## Секция 5 — Ксенон изход (P-MOSFET high-side)

```
KL30 [F2: 15A] ──► IRF4905 Source
                   IRF4905 Drain ──► [D2 — 1N5408] ──┐
                   IRF4905 Gate ──► [R9 — 10kΩ] ──► KL30 (pull-up → FET OFF по default)
                              └──► [Q2 — 2N7000 Drain]
                                   2N7000 Source ──► GND
                                   2N7000 Gate  ──► [R10 — 1kΩ] ──► GPIO26

BCM xenon изход ──► [D3 — 1N5408] ──┘
                                     │
                               Ксенон баласт (+12V вход)

Логика:
  GPIO26 HIGH → 2N7000 ON → IRF4905 Gate = GND → Vgs = -12V → FET ON → ксенон ON
  GPIO26 LOW  → 2N7000 OFF → R9 pulls Gate = 12V → Vgs = 0V → FET OFF
  D2/D3: развръзка — нито BCM, нито ние не се "виждат" взаимно
```

---

## Секция 6 — Реле за габарити (K1)

```
GPIO27 ──► [R11 — 1kΩ] ──► BC547 база
                            BC547 емитер ──► GND
                            BC547 колектор ──► Реле K1 бобина (-)
                            Реле K1 бобина (+) ──► KL30 [F3]
                            [D8 — 1N4007] антипаралелно на бобината (flyback)

Реле K1 NO  ──► KL30 [F3]
Реле K1 COM ──► [D4 — 1N4007] ──┐
                                  │
BCM габарити изход ──► [D5 — 1N4007] ──┘
                                        │
                                 Габарити (предни + задни)
```

---

## Секция 7 — Реле за мъгла (K2)

```
(Идентично на K1, GPIO14, D6/D7, R12)

GPIO14 ──► [R12 — 1kΩ] ──► BC547 база
                            BC547 емитер ──► GND
                            BC547 колектор ──► Реле K2 бобина (-)
                            Реле K2 бобина (+) ──► KL30 [F3]
                            [D9 — 1N4007] flyback

Реле K2 NO  ──► KL30 [F3]
Реле K2 COM ──► [D6 — 1N4007] ──┐
                                  │
BCM мъгла изход ──► [D7 — 1N4007] ──┘
                                      │
                               Предни мъгли
```

## ESP32 Пинове — обобщение

| GPIO | Посока | Функция |
|------|--------|---------|
| 34 | Вход (ADC) | Напрежение акумулатор (47k/10k делител) |
| 35 | Вход | KL18/ACC оптрон |
| 32 | Вход | AUTO сигнал оптрон |
| 33 | Вход (INT) | Unlock pulse оптрон |
| 26 | Изход | Ксенон MOSFET (2N7000 драйвер) |
| 27 | Изход | Габарити реле (BC547) |
| 14 | Изход | Мъгла реле (BC547) |
